# Original illustrative demo media

These images were generated specifically for Apartment Ledger on September 2, 2026 with OpenAI's built-in image-generation tool. They are fictional, contain no people, brands, addresses, or property names, and are presented in the interface as illustrative media rather than evidence of any listing.

The active demo set contains 15 distinct apartment interiors, one per candidate. The production prompts requested varied but plausible living-room and kitchen views across historic, industrial, modern, cottage, and downtown rental styles, plus:

- a modest vintage apartment living room with an uninterrupted desk wall;
- a compact older rental kitchen opening into a living area;
- a realistically proportioned modest bedroom with visible clearance;
- a fictional two-bedroom architectural floor plan with no labels or dimensions.

All prompts required realistic geometry and prohibited logos, text, watermarks, recognizable branded objects, people, and listing-specific claims. The generated PNGs were converted to optimized WebP files for the application. A prior illustrative floor-plan asset remains in this directory but is not shown by the current one-photo-per-listing interface.
